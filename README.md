# Tecno-Flash

**Tecno-Flash** es una aplicación móvil que desarrollé como proyecto académico para poner en práctica mis conocimientos de programación y desarrollo de aplicaciones para Android.

La idea es tener una aplicación en la que las personas puedan consultar productos tecnológicos, agregarlos a un carrito y simular una compra. También cuenta con opciones para que los vendedores administren sus productos y el administrador pueda gestionar los usuarios y las compras.

## ¿Qué podemos hacer en Tecno-Flash?

La aplicación tiene tres perfiles:

### Comprador
- Ver los productos disponibles.
- Consultar la información de cada producto.
- Agregar productos al carrito.
- Realizar una compra de prueba.
- Consultar su perfil.

### Vendedor
- Registrar nuevos productos.
- Modificar la información de los productos.
- Eliminar productos.

### Administrador
- Consultar los usuarios registrados.
- Editar y eliminar usuarios.
- Consultar los productos.
- Revisar las compras y cambiar su estado.

También cuenta con una pantalla de bienvenida y una opción de autenticación mediante huella digital, siempre que el dispositivo tenga disponible esta función.

## ¿Con qué se desarrolló?

Para construir la aplicación utilicé:

- **Kotlin:** lenguaje de programación.
- **Android Studio:** entorno de desarrollo.
- **XML:** diseño de las pantallas.
- **Gradle:** configuración y compilación del proyecto.
- **AndroidX Biometric:** autenticación biométrica.

## ¿Cómo puedo ejecutar el proyecto?

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto desde Android Studio.
3. Esperar a que termine la sincronización de Gradle.
4. Conectar un celular Android o iniciar un emulador.
5. Ejecutar la aplicación.

## Algunas cosas que debes tener en cuenta

Esta versión de Tecno-Flash es un prototipo académico. Los datos se manejan temporalmente dentro de la aplicación, por lo que no se conservan al cerrarla.

El proceso de compra es una simulación y todavía no está conectado a una pasarela de pagos ni a una base de datos externa.
